Cara Aktifkan ACL & Telnet
di Router Fiberhome

Panduan langkah-demi-langkah untuk semua seri populer — HG6145F1, HG6145D2, HG6245F/L, AN5506 — dari firmware stock hingga custom webui. Langsung dari layar router Anda.

1. Login ke Router

  1. 1
    Hubungkan HP/PC/laptop ke WiFi ONT, atau colok kabel LAN ke salah satu port LAN ONT.
  2. 2
    Buka browser (Chrome/Edge/Firefox), ketik alamat IP ONT: biasanya http://192.168.1.1 (default) atau http://192.168.100.1 (default sebagian operator).
  3. 3
    Masukkan kredensial admin:
    username : admin
    password : <password Anda>
    (Untuk ONT baru bawaan ISP: password biasanya tertera di stiker belakang ONT — format Fh@XXXXXX, contoh Fh@AB12CD.)
  4. 4
    Klik Login. Jika salah, ada jeda 30 detik sebelum Anda bisa coba lagi (jangan tekan berulang).
💡 Password bisa Anda lihat/ubah di mode advanced: Administration / Management → Account atau Security → ACL Settings untuk manajemen akses.

2. Cara Aktifkan ACL (Access Control List)

ACL menentukan siapa (IP/subnet/port) yang boleh mengakses layanan tertentu di ONT (web UI, telnet, ping, DNS, dll). Default banyak ONT: ACL nonaktif atau hanya membolehkan akses LAN.

Langkah (Web UI — firmware stock / custom):

  1. 1
    Setelah login, pilih menu Security atau Firewall (nama menu bisa berbeda per firmware — lihat tabel di bagian 5).
  2. 2
    Pilih sub-menu ACL Settings / ACL / Access Control. Anda akan melihat halaman acl_setting.html dengan dua radio button: Enable dan Disable.
  3. 3
    Centang Enable, lalu klik Apply / Save / OK.
  4. 4
    (Opsional) Untuk menambah aturan baru, klik Add:
    - Start IP – End IP: rentang yang diizinkan (mis. 192.168.1.0 – 192.168.1.254)
    - Protocol: ALL untuk semua layanan, atau spesifik (HTTP/Telnet/SSH/ICMP/dll)
    - Direction: LAN (dari sisi lokal) atau WAN (dari internet)
    - Enable / Active: Yes
    Klik Apply.
  5. 5
    Aturan aktif langsung tersimpan (X_FH_ACL Rule ... Enable = 1). Tidak perlu reboot.

📌 Format alamat yang dipakai:

⚠️ Catatan penting: Jika ONT Anda diprovisioning oleh ISP (ada aturan TR-069 dari ACS), aturan ACL bisa diabaikan/dikunci oleh provisioning server — disimpan di config tapi tidak diterapkan. Perubahan yang "benar-benar permanen" baru bisa setelah ONT di-unprovisioned atau setting lokal diizinkan.

3. Cara Aktifkan Telnet

Telnet pada Fiberhome sangat berguna untuk troubleshooting (CLI seperti display, show, ping dari dalam ONT). Aktifkan sebagai berikut.

Metode A — Web UI (paling mudah):

  1. 1
    Menu Security → ACL Settings (sama seperti Langkah 2 di atas)
  2. 2
    Cari daftar aturan ACL yang ada. Cari yang Protocol = Telnet atau ALL dengan Direction = LAN.
  3. 3
    Jika tidak ada, klik Add → isi: Protocol = Telnet (atau ALL), Direction = LAN, Source IP = 192.168.1.0 – 192.168.1.254, Enable = Yes.
  4. 4
    Pastikan ACL global Enable = Yes (paling atas halaman). Klik Apply.
  5. 5
    (Jika opsi khusus Telnet terpisah) masuk menu Administration / Management → Access Control, aktifkan Telnet Access = Enable.

Metode B — Lewat CLI Telnet (setelah menyala):

telnet 192.168.1.1
# Login: gpon
Username : gpon
Password : Fh@XXXXXX        # 6 hex terakhir dari MAC, UPPERCASE
# Masuk ke CLI, lalu:
User> enable
Password : Fh@XXXXXX
Config#

Jika port 23 sudah terbuka tapi CLI menolak perintah khusus ("Unknown command"), firmware Anda terkunci — gunakan Local Upgrade custom webui (lihat bagian 6) atau menu ACL Settings di atas.

4. Verifikasi Bahwa ACL/Telnet Bekerja

  • Ping ke ONT dari PC Anda ping 192.168.1.1 → dapat balasan
  • Telnet telnet 192.168.1.1 → muncul prompt login
  • Web UI lain bisa diakses hanya dari IP yang diizinkan (coba dari HP lain di WiFi yang sama — jika di-block, itu sukses)
  • Di dalam CLI: ketik display version, system, ? → muncul daftar perintah

6. Mode Custom Webui (Unlock CLI Terkunci)

  1. 1
    Download custom-webui.bin (proyek open-source Fiberhome HG6145F1 Custom Webui — github.com/numberonedz/hg6145f1-custom-webui).
  2. 2
    Login ke web UI ONT → Management → Device Management → Local Upgrade
  3. 3
    Pilih custom-webui.bin → Update File → akan muncul "Upgrade failed" (itu memang tujuannya — patch berbasis OMCI) → refresh browser
  4. 4
    Setelah refresh, web UI berubah (ada badge "Custom WebUI by Adel" di login) → semua menu & kemungkinan perintah CLI terbuka
  5. 5
    Untuk mengaktifkan telnet setelah custom webui: menu Security → ACL Settings (sekarang fungsional), atau lewat telnet CLI: config, shell, dsb.

7. FAQ & Troubleshooting

T: Port 23 (telnet) tertutup walau sudah Enable?

J: Beberapa ONT butuh aturan ACL khusus untuk telnet (bukan hanya mengaktifkan ACL global). Tambah aturan: Protocol=Telnet, LAN, IP=192.168.1.0–254, Enable=Yes.

T: Login web UI gagal dengan "3 times Error. 30 minutes locked"?

J: Salah password 3 kali berturut-turut mengunci web UI. Tunggu sampai countdown habis, atau factory reset ONT (pin hole 10 detik) — reset menghapus semua konfigurasi, jangan dilakukan kecuali benar-benar perlu.

T: ONT tidak bisa dikonfigurasi sama sekali setelah restart?

J: Itu tanda ONT Anda di-manage via TR-069 oleh operator. Hubungi ISP Anda; setting akan di-push kembali saat ACS polling (biasanya tiap 5–15 menit).

T: Saya butuh tampilan lebih profesional untuk Tutorial ini?

J: Anda bisa print tutorial ini ke PDF lewat browser: Ctrl+P → Save as PDF. Tampilan akan otomatis rapi (print mode sudah disiapkan).

T: Apakah aman membuka ACL & Telnet?

J: Aman selama hanya di jaringan internal Anda. Jangan pernah expose ke internet (WAN) tanpa VPN — itu membuka jalan bagi orang asing masuk ke jaringan rumah Anda.
